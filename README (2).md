# KaryaDigital - Marketplace Produk Digital

Platform marketplace sederhana, cepat, dan responsif untuk menjual aset digital (tempalte dan aset digital).

## Fitur
- **Katalog Produk:** Filter kategori dan tampilan grid modern.
- **Dashboard Buyer:** Halaman ringkasan untuk melihat produk yang sudah dibeli dan tombol download instan.
- **Checkout / Cart Slide-over:** Simulasi keranjang belanja.
- **Responsive:** Optimal dapat dibuka di berbagai perangkat Mobile, Tablet, dan Desktop.

## Cara Menjalankan
1. Clone atau download repository ini.
2. Buka file `index.html` langsung di browser Anda, atau gunakan Live Server di Visual Studio Code.
